# shop-disclosure-kit

## 安裝

```bash
npm i github:Jeffrey0117/shop-disclosure-kit   # 或直接複製 index.js
```

## 用法

```js
const create = require('shop-disclosure-kit');
const x = create({ /* opts */ });
```
